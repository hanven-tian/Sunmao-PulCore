# 榫卯 PulCore

榫卯（PulCore）是一个面向企业级业务系统的元数据驱动微内核低代码平台。平台以“榫”为稳定内核、以“卯”为标准扩展接口：内核负责插件生命周期、依赖注入、元数据模型、动态 API、ACL 与事件总线，业务能力通过插件自由组合。

PulCore 对标主流低代码平台的完整官方能力矩阵，社区能力和传统企业版能力在榫卯中统一永久免费，不设置功能付费墙。所有插件都遵循相同的安装、依赖、启停、失败隔离和能力声明规范。

> 当前阶段：可运行微内核、动态业务 API 与全量插件能力注册已打通。

## 为什么是“榫卯”

传统木作中的榫卯通过稳定构件和标准连接方式组合成复杂整体。PulCore 将这一思想映射到软件架构：

- **榫（Core）**：小而稳定的微内核，负责插件生命周期、依赖注入、模型、权限、事件和 API。
- **卯（Extension Point）**：统一扩展契约，插件通过依赖、能力声明和生命周期接入。
- **构件（Plugin）**：业务功能可独立安装、启停、升级和测试，插件故障不会拖垮整个内核。
- **建筑（Application）**：门户、页面、模型、流程和行业应用都由插件组合形成。

## 核心设计原则

1. **微内核优先**：业务能力不写入内核，避免平台随需求增长而失控。
2. **元数据单一事实源**：数据表、CRUD API、表单、列表和权限来自同一份 Model 定义。
3. **一切皆插件**：平台功能、行业能力和集成适配器使用相同扩展规范。
4. **默认安全**：模型、操作、数据行和字段四级权限贯穿动态 API。
5. **故障隔离**：插件启用失败会被记录，不影响其他插件继续运行。
6. **全部免费**：不通过企业版人为切割 SSO、AI、工作流、数据源或运维能力。

## 架构概览

```text
应用层：门户 / 页面 / 施工设备示例 / 移动采集入口
  ↓
能力层：工作流 / AI / 多数据源 / 图表 / 文件 / 工业物联网
  ↓
元数据层：Model / UI Schema / 动态 CRUD API / ACL
  ↓
微内核：Plugin Manager / DI Container / Event Bus
  ↓
基础设施：Node.js HTTP / 数据存储 / Docker / 外部连接器
```

插件加载流程：发现插件 → 校验名称 → 安装模型 → 解析依赖 → 按序启用 → 发布能力就绪事件。

## 快速开始

要求 Node.js 22 或更高版本，无第三方运行时依赖。

```bash
npm test
npm start
```

服务默认监听 `http://127.0.0.1:3000`。

```bash
curl http://127.0.0.1:3000/health
curl -H 'x-user-role: admin' http://127.0.0.1:3000/api/models/portal
curl -H 'x-user-role: admin' http://127.0.0.1:3000/api/model-portal:list
```

## Docker 容器化运行

仓库同时提供控制台和微内核 API 的双服务编排：

```bash
docker compose up --build -d
```

- 控制台：`http://localhost:3000`
- 微内核 API：`http://localhost:3001`
- 健康检查：`http://localhost:3001/health`

停止服务可运行 `docker compose down`。API 容器带健康检查，控制台会等待微内核服务就绪后启动。

## 动态 API

- `GET /api/models/:model`：读取模型定义
- `GET /api/model-:model:list`：列表、分页、筛选和排序
- `GET /api/model-:model:get/:id`：详情
- `POST /api/model-:model:create`：创建
- `PUT /api/model-:model:update/:id`：更新
- `DELETE /api/model-:model:delete/:id`：删除

列表参数示例：`?page=1&pageSize=20&status=online&sort=-createdAt`。

## 插件管理 API

插件管理接口要求请求头 `x-user-role: admin`：

```bash
curl -H 'x-user-role: admin' http://127.0.0.1:3000/api/plugins
curl -X POST -H 'x-user-role: admin' http://127.0.0.1:3000/api/plugins/ai-data-qa:disable
curl -X POST -H 'x-user-role: admin' http://127.0.0.1:3000/api/plugins/ai-data-qa:enable
```

当插件仍被其他启用插件依赖时，内核会拒绝停用并返回依赖者列表。
